# host_tests

脱机测试：不接开发板、不需要 ESP-IDF，用系统编译器直接跑纯逻辑。

## 运行

```sh
sh host_tests/run.sh          # 默认 gcc，可用 CC=clang sh host_tests/run.sh 覆盖
```

产物落在 `build/host/test_wbus`（`build/` 已被忽略），失败时退出码非 0。

## 覆盖范围

`test_wbus.c` 共 70 项断言，覆盖总线骨架：

- 注册表：注册、重名拒绝、按名查找、越界访问
- 调用：未知对象、未知方法、缺 `.`、缺必填参数、未知参数、裸 token
- 参数：范围上下界、非数字、布尔写法、`auto` 与数字信道、MAC 解析、默认值填充、
  重复键取首个、`name="a b"` 引号与空格、多空格容错、参数顺序无关
- 回执：多行数据 + `OK` 收尾、处理函数返回错误时的文案
- 事件：订阅匹配、非匹配不投递、带载荷与不带载荷的行格式
- 边界：超长行、参数个数上限

## 约定

`mock/` 里是 `esp_err.h` 与 `esp_log.h` 的极简替身，只够编译 `wbus`（它不依赖任何 ESP-IDF 组件）。
新增脱机用例时不要引入需要 FreeRTOS 或 esp_* 的源文件，否则这层就不再是"拔电也能跑"。
