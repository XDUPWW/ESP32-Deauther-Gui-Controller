## 3. 稳定性与压力结论

- **60 轮 STATUS**：首值 = 末值（109420），`spread=0`，通过。
- **连续 4 次扫描**：每次都返回完整列表并打印 `SCAN_END <n>`，无丢响应，通过。
- **300 条 PING 洪泛**：**300/300 全部响应**（RX 环形缓冲已从 256 B 提到 4 KB），之后固件仍正常响应，通过。
  - 用例断言收紧到"≥95% 响应"，低于即判定 RX 缓冲/解析回归。
- **垃圾字节注入**（0x01–0x1F + CRLF）：不崩溃，随后 PING 正常，通过。
- **超长行（200 字节）**：`ERR line too long` 并丢弃该行，之后仍正常，通过。

## 6. 测试中发现并修复的缺陷

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 屏幕持续闪烁 | 触摸原始值空闲漂移被当成连续按压，校准界面反复重绘 | 800 ms 静置 + 连续 3 次稳定判据 + 按压后锁存到松手 |
| 2 | 点屏幕完全无反应 | 误用 PENIRQ（GPIO36）门控，该板未接该信号（实测恒为 1） | 移除 IRQ 门控，改用原始值窗口 + 稳定判据 |
| 3 | 校准界面点四角无记录 | 判据写成 `stable==3 && !prev_down`，而 `prev_down` 每 tick 更新，永不成立 | 稳定到 3 立即记录并锁存，松手清零 |
| 4 | 触摸坐标与显示错位 | 触摸映射多做了一次 180° 变换，与显示翻转叠加 | 由四角校准自动解算轴序与增益（`ax/ay` + 可负增益） |
| 5 | 显示反转/上下颠倒 | ILI9341 需反色 + 面板装反 180° | `invert_color(true)` + `mirror_x/mirror_y` |
| 6 | 状态灯干扰显示 | `LED` 定义在 GPIO2，而 CYD 的 GPIO2 是 LCD 的 D/C 线 | 改用板载 RGB LED（GPIO4，低电平点亮） |
| 7 | 扫到 35 个网络后固件失联 | LVGL 默认 32 KB 堆装不下 35+ 列表项 | LVGL 堆 64 KB + 列表行数上限 |
| 8 | 扫描期间界面冻结、串口停摆 | 阻塞式 `WiFi.scanNetworks()`（3–7 s）跑在主循环里 | 扫描移入独立任务 `scan_task` |
| 9 | 按下 Scan 后卡住 | 按钮回调在 LVGL 任务里直接执行扫描命令 | 按钮只入队，主循环执行 |
| 10 | 启动瞬间被误判为按压 | 上电瞬态被当成按下 | 校准启动后 800 ms 内不接收输入 |
| 11 | 校准数据无法保存 | 组件 `REQUIRES nvs_flash` 在该 IDF 版本下未传 include 路径 | 依赖倒置：app 注入 `wireless_ui_storage_ops_t` |
| 12 | `STATUS` 反映不了 UI 状态 | 协议缺字段 | 新增 `ui=<0\|1>`、`TOUCH`、`CALIBRATE` |
| 13 | 扫描后只显示 `chn`，没有 SSID/BSSID | LVGL 列表行里 `snprintf` 的格式串被截断/字段顺序错 | 重写列表行格式并加中文子集字库 |
| 14 | 中文 SSID 显示方块 | LVGL 自带 CJK 子集 191 KB 太占空间，默认字体又没汉字 | 自建 57 KB 子集（`tools/gen_cjk_font.py`），未收录字显示空白 |
| 15 | 一级菜单里出现 SCAN，Probe 页却用不到 | 菜单把"扫描"当成功能 | 扫描下沉为模式页里的按钮；Probe 页无扫描 |
| 16 | 扫描和目标选择在两页之间来回跳，操作混乱 | 独立的"选择目标"页 | 模式页即工作页：扫描 + 选目标 + 开始/停止 + STATS 同一处（固件与上位机都改） |
| 16b | 选目标只能靠拖动滚动条，长列表里挑起来别扭 | 选表嵌在页面里，高度被按钮挤压 | 上位机改成弹窗选目标：过滤 SSID、双击勾选、全选/清空/反选、窗口内重新扫描 |
| 17 | 模式页按钮占了 3 行，AP 列表只剩 1–2 行可见 | 按钮高度统一 36 px | 模式页/Evil 页用 30–32 px 紧凑按钮 |
| 18 | 上位机一键 `NET` 行报 `KeyError: 'ch'` | `protocol.parse_net` 返回键名是 `channel`，表格取值用 `ch` | 表格按 `channel` 取值 |
| 19 | 重扫后勾选错位（勾到了别的 AP） | 索引只对一次扫描有效，但勾选集没清 | `SCAN` 时清空勾选与单选（固件 + 上位机） |
| 20 | 逐个 `NET` 行都重建整表，扫描时闪屏/卡顿 | `_handle_line` 每行都 `_fill_all_trees()` | 改为增量插入 + 扫描结束统一刷新标签 |
| 21 | 屏上选目标要在页面里滑小列表，行数少、还挤掉按钮 | AP 列表嵌在模式页里，320×240 只够 2–3 行 | 改成 `lv_layer_top()` 上的模态弹窗（308×228，可滑 30 行，`All/None/Back/OK`）；点行只改该行 label，不重建列表 |
| 22 | 弹窗行数超过扫描结果 / 反复开关后堆下降 | 列表重建无上限、快照缺失 | 行数上限 `LIST_ROWS=30` 并断言 `items == min(nets,30)`；进出弹窗用快照还原；连开 3 次堆不变 |
| 24 | **deauth 看起来在打、实际大半帧没发出去**（`d=` 涨，客户端无反应） | 注入写在混杂回调里，一次连发 16 帧单播；每帧都在等 ACK 超时，很快撞满 TX 缓冲，`esp_wifi_80211_tx()` 返回 `ESP_ERR_NO_MEM(257)` 而返回值被忽略 | 回调只入队（16 深），主循环按 1 ms 出队注入，失败退避 5 ms 重试；单次束改成 2 单播 + 1 广播；`STATUS` 增加 `txok/txerr/txerr_nomem/txec/txdrop`。重测 `txerr` 从 720 帧里 463 次失败降到 0（安静环境）/ 可控重试 |
| 25 | 控制帧触发源形同虚设 | 地址字段的存在性判据用 `sig_len >= 22`，而 RTS / PS-Poll 只有 16 字节载荷 + 4 字节 FCS = **20**，永远进不了分支 | 按帧类型分开判：控制帧 `>= 20`（只有 Addr1/Addr2），管理/数据帧 `>= 22/28` |
| 26 | 客户端完全静默时永远不产生 deauth | 嗅探触发需要先看到该 BSS 有流量 | 增加盲发兜底：每 500 ms 给当前 AP 发一帧广播 deauth（`BLIND_DEAUTH_PERIOD_MS`），`blind=` 计数可观测 |
| 28 | 只伪造 AP→STA，部分客户端/AP 组合不买账 | 只有一条方向可打 | 每束追加 1 帧 **STA→AP**（Addr1=AP、Addr2=客户端）让 AP 拆关联；`STATUS` 加 `rev=`；单播束从 2 降到 1，`txerr` 从 144 降到 2 |
| 27 | reason code 非法输入被静默改成 1 | `parse_reason()` 对越界/非数字一律返回 1，用户以为设置生效了 | 换成会报错的解析器（0/负数/越界/非数字 → `ERR`）；非标准值可用但打印 `INFO`；新增 `random` 模式与 `REASON` 查询命令；LVGL 加 `R:x` 循环按钮，上位机加"自定义"输入框 |
| 23 | 指令洪泛丢行：300 条 PING 只回 233–255 条 | `HardwareSerial` 默认 RX 环形缓冲只有 256 B，突发超过就整行丢弃 | `Serial.setRxBufferSize(4096)` 后再 `begin()`（`SERIAL_RX_BUFFER_SIZE`）；用例断言收紧到 ≥95%，实测 **300/300** |

## 7. 未覆盖 / 已知限制

1. **deauth 的可解码性**：11n 射频解不出 HE PPDU，所以"哪台客户端在线"看不全。
   嗅探命中（`rxm`）只在能解出该 BSS 的上行帧时才增长；拉不到命中时靠 `blind=` 兜底继续发广播帧。
2. **5 GHz 上的 Evil Twin**：克隆 AP 仍用 `WiFi.softAP(...)`，5 GHz 能否开 AP 未验证。
3. **完整钓鱼流程**：未用第三台设备走"连上克隆 AP → 提交凭据 → 串口读取"全链路。
4. **触摸校准精度**：四角线性映射，边角误差约 ±5 px（按钮高 30–36 px，不影响点击）。
5. **自动化不发真实 deauth**：避免干扰周围网络，攻击类命令只验证参数与计数。
6. **C5 版本**：编译、5G 扫描、双板交叉验证已验证；LVGL 界面在 C5 上不编译
   （宏 `depends on IDF_TARGET_ESP32`），属设计选择。
7. **上位机只做过无头验证**：真实窗口交互（鼠标点表、确认框）由人工确认，未做 UI 自动化点击。
8. ~~屏上弹窗的视觉未验证~~ **已人工确认正常**（卡片描边/圆角、字号、行高、滑动、点击）。
